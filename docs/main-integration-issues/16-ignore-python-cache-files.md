# Ignore Python cache files

Suggested labels: `chore`, `repository-hygiene`
Priority: Low

## Summary

Ignore Python bytecode and cache directories generated by repository validation
scripts.

## Value

Running Python-based validation locally creates `__pycache__/` directories and
`.pyc` files. Ignoring them prevents accidental commits and keeps `git status`
focused on meaningful changes.

## Existing implementation to reuse

## Required implementation for `main`

Add the two ignore patterns to the root `.gitignore`. No production-code change
is required.

Before adding them, confirm no cache files are already tracked. If any are
tracked, remove them from the Git index without deleting developers' local
files.

## Acceptance criteria

- Running Python validation does not add cache files to `git status`.
- Existing source, fixtures, and intentionally committed Python files remain
  visible to Git.
- No broad pattern hides unrelated repository content.

## Verification

```sh
git check-ignore -v --no-index scripts/__pycache__/example.cpython-313.pyc
git check-ignore -v --no-index example.pyc
```

Both paths should match the new rules. After any repository Python script is
added, compile or run it and confirm its cache paths do not appear in
`git status --short`.
